Tentang Saya

Halo! Saya Bellatrix Abdul Rahman (biasa dipanggil Abdul). Saya siswa jurusan Web Development di SMK PGRI 01 Sukorejo yang saat ini sedang aktif menjalani kegiatan Praktik Kerja Lapangan (PKL).

Saya menguasai pengembangan web modern dari sisi frontend hingga backend menggunakan React, Next.js, dan Laravel. Selain coding, saya berpengalaman dalam administrasi jaringan komputer seperti penataan routing MikroTik, pemisahan trafik, hingga jaringan serat optik (Fiber Optics & GPON).

Laravel React.js Next.js JavaScript PHP MikroTik RouterOS Access Points (UniFi/Ruijie/TP-Link) Fiber Optics & GPON ONT

Proyek & Pengalaman

Real-Time Traffic Management

Sistem monitoring dan manajemen trafik jaringan terintegrasi berbasis Laravel dan WebSockets untuk memantau penggunaan bandwidth secara langsung (real-time).

Custom Hotspot Portal UI

Hasil eksperimen bikin antarmuka login Hotspot MikroTik kustom yang responsif, teroptimasi, dan ringan memanfaatkan HTML, CSS, serta JavaScript.

Traffic Isolation & Bandwidth Queue

Penerapan Mangle Rules, Policy-Based Routing, dan Queue Management pada MikroTik RouterOS untuk pemisahan otomatis trafik game dan video streaming.

Optical Network Infrastructure

Pengujian dan pengukuran redaman jaringan serat optik dengan OPM, konfigurasi GPON ONT (ZTE/FiberHome), serta pengelolaan ODP.

Interactive Liquid Glass Portfolio

Eksperimen portofolio interaktif dengan efek glassmorphism, animasi tali SVG merespons scroll, serta fitur kalkulasi dan theme switcher.

Home Server & Network Lab

Proyek sampingan merakit lab server lokal mandiri untuk pengujian deployment web Laravel/React serta manajemen perangkat jaringan lokal.
